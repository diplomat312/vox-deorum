# v0.12.0: 2026-08-02

The integration and setup release: players now get in-game diplomacy, guided configuration, broader model support, and a more reliable game-session flow.

## In-Game Diplomacy

- Added a diplomacy panel, conversation flow, deal editing, and a new deal screen inside Civilization V.
- Connected diplomacy across Civilization V, the bridge service, MCP server, and Vox Deorum agents.
- Improved chat streaming, notifications, leader handling, and deal reliability.

## Models and Providers

- Added Codex provider and proxy support, including login, built-in tools, streaming, and multiple Codex instances.
- Added model discovery, rule-based resolution, model tiers, and reasoning-effort controls.
- Improved Claude Code support, retries, usage-limit handling, and summarized reasoning.

## Setup and Sessions

- Added guided setup for API keys, paths, model definitions, and agent mappings.
- Added game-session configuration for player seating, game setup, and launch controls.
- Simplified and polished the configuration and session interfaces.

## Reliability

- Improved loading, startup sequencing, active-turn handling, concurrency, and crash recovery.
- Improved Oracle continuation and shutdown behavior.
- Strengthened streaming recovery, timeouts, and tool-call handling.

## Documentation and Maintenance

- Expanded player and developer documentation for setup, architecture, operations, Codex, diplomacy, and Civilization V integration.
- Simplified the web UI, diplomacy code, agent structure, tests, and repository tooling.
- Removed dead code and refreshed installer and release tooling.

This release contains 174 non-merge commits since v0.11.0, changing 535 files with 42,287 additions and 11,127 deletions.
